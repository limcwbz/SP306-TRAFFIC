# SP306-TRAFFIC

브라질 상파울루주 세 도로의 구간별·방향별 교통상황을 **15분 단위**로 수집하고, 매일 **한국 시간 08:00**에 직전 브라질 하루(00:00~23:59)의 엑셀·그래프 보고서를 메일로 보냅니다.
모든 시각은 **브라질 현지 시간(America/Sao_Paulo, UTC−3)** 기준입니다.

| 도로 | 구간 | 방향 이름 |
|---|---|---|
| SP-306 (SP-304 분기점 → SP-308 분기점, 약 19.3 km) | 0–5 km, 5–10 km, 10–19.3 km (3구간) | 하행 / 상행 |
| SP-330 Anhanguera (SP-133 교차점에서 남쪽 4 km) | 2 km × 2 | 남행 / 북행 |
| SP-308 Rodovia do Açúcar (23.0177°S 47.4374°W → 23.0757°S 47.4032°W, 약 7.4 km) | 2 km 단위 4구간 | 남동행 / 북서행 |

## 워크플로

| 워크플로 | 실행 | 하는 일 | 결과 |
|---|---|---|---|
| `collect` | 15분마다 (UTC 3·18·33·48분) | TomTom 속도 조회 | `data` 브랜치에 `data/날짜.jsonl` 누적 |
| `daily-report` | 매일 KST 08:00 (UTC 23:00) | 엑셀 + **독립형 HTML 보고서** + 그래프 + 요약장표 생성, Gmail 발송 | 메일 (첨부: 엑셀 + HTML) (수동 실행 시 Artifacts `report-output`) |
| `speed-export` | 수동 | TomTom 15분 속도 로그를 **기간별 엑셀**로 내보내기 | Artifacts `traffic-speed` (30일 보관) |
| `volume` | 매일 UTC 10:30(KST 19:30) + 수동 | ARTESP 공개 **일 통행량(차량 대수)** 엑셀 | Artifacts `traffic-volume` (30일 보관) |

## 데이터는 어디에 저장되나

- **TomTom 15분 속도 원본**: `data` 브랜치의 `data/날짜.jsonl` (한 줄 = 15분 슬롯 하나, JSON). **기본 브랜치(main)가 아니라 `data` 브랜치**를 열어야 보입니다.
- 엑셀로 보려면 `speed-export` 를 실행하세요 (아래).
- 일일 보고 엑셀과 HTML 은 메일 첨부로 오며, 파일은 저장되지 않습니다(수동 실행 시 Artifacts 7일).

## 메일에 첨부되는 HTML 보고서

매일 메일에는 **엑셀 + HTML(`SP306_traffic_BRT_날짜.html`)** 이 함께 첨부됩니다. HTML 은 그날(브라질 00:00~23:59) **GitHub 가 수집한 TomTom 기록을 문서 안에 모두 포함**한 정적 보고서라, 첨부를 저장해 더블클릭만 하면 인터넷·API 키 없이 열립니다.
- 구성: 도로별로 도식도 → 구간별 하루 요약(평균·최저·정체 횟수) → 시간대별 평균 속도 표 → 15분 속도 추이 그래프(마우스를 올리면 슬롯별 값) → ARTESP 일 통행량(우리 구간 안은 파란색), 마지막에 혼잡 기준과 도로 세그먼트 기준.
- 브라우저 화면(`sp306_traffic.html`)과 달리 「실시간 조회」 기능은 없고, 새로 고쳐도 값이 바뀌지 않습니다(그날의 기록).
- 수집이 절반 미만인 날은 문서 위에 경고가 표시되고, 값은 수집된 칸만으로 계산합니다.

## 브랜치

- `main` : 코드
- `data` : 수집 데이터(`data/날짜.jsonl`), `state.json`(발송 기록), `offsets.json`, `volume/summary_latest.csv`
  - 처음 실행할 때 `seed/` 폴더 내용으로 **자동 생성**되므로 직접 만들 필요가 없습니다.

## 필요한 Secrets (Settings → Secrets and variables → Actions → Repository secrets)

| 이름 (밑줄 입력이 안 되면 괄호 안 이름) | 값 |
|---|---|
| `TOMTOM_API_KEY` (`TOMTOMAPIKEY`) | TomTom Traffic API 키 |
| `MAIL_TO` (`MAILTO`) | 수신자 이메일 |
| `SMTP_USER` (`SMTPUSER`) | 발신 Gmail 주소 |
| `SMTP_PASS` (`SMTPPASS`) | Gmail **앱 비밀번호** (공백 없이 16자) |

`speed-export`, `volume` 은 Secrets 가 필요 없습니다. **이 저장소는 공개입니다. 키·비밀번호·메일 주소를 코드나 커밋에 넣지 마세요.**

## TomTom 15분 속도를 엑셀로 받기 (`speed-export`)

Actions → `speed-export` → Run workflow
- `from`, `to` : 브라질 날짜(YYYY-MM-DD). 둘 다 비우면 기록 전체
- 실행이 끝나면 화면 맨 아래 **Artifacts → traffic-speed** 를 내려받습니다.
- 엑셀 시트: **15분 기록**(도로·구간·방향별 세로 형식) / **일별 요약**(평균·최저·정체 횟수) / **수집 현황**(날짜별·시간별로 몇 칸이 수집됐는지) / 설명

## 시험 실행 (`daily-report`)

Actions 탭 → `daily-report` → Run workflow
- `dry_run` 체크(기본) : 메일을 보내지 않고 결과 파일을 artifact(`report-output`)로 올립니다.
- 체크 해제 + `mail_to` 에 본인 주소 : 본인에게만 실제 발송해 첨부·그래프를 확인합니다.

## 통행량(차량 대수)

속도(TomTom)와는 별개로 **ARTESP 공개 자료**(SAT 자동 교통량 계수기)의 일 통행량을 집계합니다. 일일 보고의 도로별 속도 표 아래에 붙고, **TomTom 속도를 집계하는 구간 안의 계측점은 파란색**으로 표시됩니다. 대상 도로·km 범위·이상치 기준은 `volume_config.json` 에서 바꿉니다. SP-306 은 ARTESP 자료에 없습니다.

## 혼잡 기준

현재 속도 ÷ 자유 흐름 속도: 원활 ≥ 80%, 서행 60~80%, 지체 40~60%, 정체 < 40%. 바꾸려면 `thresholds.json` 을 고치세요(`smooth` > `slow` > `delay` > 0).

## 알려진 한계

- **GitHub 무료 스케줄은 15분 주기를 지키지 못합니다.** 실측(2026-11-21~23)에서 예약 164회 중 약 49회(30%)만 실행됐고 간격은 39~72분이었습니다. GitHub 문서도 스케줄 이벤트가 부하가 높을 때 지연되거나 일부 실행이 버려질 수 있다고 안내하며, 버려진 실행은 기록에 남지 않습니다. 건너뛴 15분 슬롯은 TomTom 무료 API가 과거 값을 주지 않아 채울 수 없습니다. `speed-export` 엑셀의 「수집 현황」 시트에서 빈 시간대를 볼 수 있습니다.
- TomTom 은 도로 세그먼트(수 km~26 km) 단위로 속도를 제공해, 같은 세그먼트에 속한 구간은 값이 같게 나옵니다(특히 SP-330·SP-308).
- 통행량은 계측점 한 곳의 하루 통과 대수이며 구간 전체의 대수가 아닙니다. 공개 자료는 며칠 늦게 올라옵니다.
- 집계 기간은 2026-11-17 ~ 2026-12-31 (마지막 보고: 2027-01-02 08:00 KST). 공개 저장소는 60일간 활동이 없으면 스케줄이 자동 중지될 수 있습니다.
